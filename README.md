One line: the museum label a museum in the year 3000 puts beside an
ordinary object from today.

> Ceiling oracle; it screamed at burnt toast, and citizens waved towels beneath it until it forgave them.

`main.py` (stdlib only) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output/entry.txt` by default). See [CANDIDATES.md](CANDIDATES.md) for the
20-candidate tournament that picked this label.
